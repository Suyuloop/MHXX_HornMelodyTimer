# MHXX 狩獵笛旋律增益計時器（v1.0.0）

Windows WPF 桌面程式。框選遊戲畫面左下角的旋律提示音符列後，程式會每 250 ms 以內附音符圖示樣板辨識最多四列，再依目前譜面更新效果計時。

## 使用方式

1. 執行 `dotnet run --project HornMelodyTimer.csproj`。
2. 按「框選遊戲畫面」，框選左下角提示列中音符可能出現的完整範圍；不必為避開右側效果文字而縮窄選區。
3. 勾選是否裝備「吹笛名人」，並核對/修改各旋律的初次效果時間及效果中延長秒數。
4. 框選後可在完整介面或疊加介面用「顯示框選位置」開關控制是否顯示不攔截滑鼠的彩色外框。按「切換疊加介面」可隱藏設定視窗並顯示半透明計時器；拖曳疊加視窗上方列可移動位置，按「返回完整介面」即可恢復設定畫面。

效果未觸發時文字為白色；生效時為黃色，剩餘 20 秒內黃白閃爍。
旋律圖示及譜面選單會使用遊戲效果提示中的音符圖示。時間欄位設定抽屜可隱藏或顯示右側效果時間與剩餘時間欄；此選項、吹笛名人勾選狀態及秒數設定會保存到 `%LOCALAPPDATA%\HornMelodyTimer\settings.json`。

## 譜面與計時

「譜面」下拉選單可切換 PDF 中的各種音符配色組合，包括紫色與白色基音譜。每個譜面會載入其旋律及時間，時間設定會依譜面分別保存。

辨識最多四列音符；具「＆」或「／」的複合旋律，若遊戲將一次觸發顯示為兩列提示，會合併為一次計時觸發；火、冰、雷、水屬性防禦強化與對應異常無效雖是複合效果，但遊戲只顯示一列，因此按一般單列旋律計算。紫・青・橙譜的複合旋律支援 PDF 的紫青橙橙與遊戲提示列中的橙青紫青兩種顯示順序。按「重置效果時間」可清除目前譜面的所有計時。紫・紅・空譜包含寒冷無效（SRS）。譜面包含「全旋律延長」時，辨識到橙紅橙會延長目前所有作用中的持續效果，不會建立額外計時；延長秒數依吹笛名人選項使用 30 或 40 秒。

## 效果時間注意事項

時間設定已依使用者提供的旋律表 PDF（atwiki「旋律表」）校正：

| 旋律 | 初次效果 / 吹笛名人 | 效果中延長 / 吹笛名人 |
|---|---:|---:|
| 自分強化 | 180 / 240 秒 | 90 / 120 秒 |
| 攻擊力、防禦力、抗性等持續效果 | 依譜面資料 | 依譜面資料 |
| 高周波、回復等瞬間效果 | 無持續時間 | 無持續延長 |
| 全旋律延長 | 不建立計時 | 延長所有作用中效果 30 / 40 秒 |

重吹時僅增加表列延長量，剩餘時間不會超過該旋律的初次效果時間上限。時間數值可在主視窗編輯；旋律與效果列表以 18 pt 顯示，效果名稱於剩餘 20 秒內黃白閃爍。

辨識會將框選區中的效果音符圖示與內附 B、G、O、P、R、S、W、Y 透明樣板做多尺寸比對，先快速排除不相似位置，再完整比對候選圖示；樣板取自使用者提供的遊戲效果音符圖示。空色 S 使用較嚴格的圖示相似度門檻，以降低極圈冰地紋理誤判；辨識候選還必須位於顏色穩定的暗色提示列背景，白音符會額外比對圖示透明區，並排除過小或過大的候選；最終讀取的整列音符必須完整符合目前譜面的旋律，不接受多出音符的前綴。這可降低一般 HUD 圖示、文字及亮色背景造成的誤判。不讀取效果文字，因此不受遊戲語系影響；畫面縮放、濾鏡、遮擋及抗鋸齒仍可能影響判斷。狀態列會顯示讀到的音符組合，若未讀到或組合不符，請用外框確認完整框住提示列中的音符圖示。
